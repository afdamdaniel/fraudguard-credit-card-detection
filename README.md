# FraudGuard: Credit Card Fraud Detection Using Machine Learning

## Overview
FraudGuard is a machine learning project that identifies potentially fraudulent credit card transactions based on transaction-related features.

## Features
- Exploratory Data Analysis (EDA)
- Machine learning-based fraud prediction
- Interactive Streamlit web application
- Real-time prediction for user-provided transaction inputs

## Tech Stack
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Matplotlib and Seaborn (for EDA, if used)

## Project Structure
```text
fraudguard-credit-card-detection/
├── fraud_detection.py
├── fraud_detection_model.sav
├── requirements.txt
├── README.md
└── .gitignore
```

## Run Locally
1. Clone this repository.
2. Install the dependencies using `pip install -r requirements.txt`.
3. Run the application using `streamlit run fraud_detection.py`.

## Disclaimer
This project is for educational purposes. Predictions should not be treated as definitive proof of fraudulent activity.
